How Assets connect

Every asset here is a delivery resource. When Sales wins a service order (SALE-####), Workforce Planning schedules a JOB-#### on the shared calendar that books specific assets (asset_ids[]) and crew (employee_ids[]) for a date range. See the shared data model.
